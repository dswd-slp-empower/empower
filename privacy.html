Privacy Policy

Effective Date: July 23, 2026

DSWD SLP Team, BSIT Batch 2027 — CTU Ginatilan Extension Campus (“we,” “our,” or “us”) operate the E.M.P.O.W.E.R mobile application (the “App”). This Privacy Policy explains how the App handles information when you use it.

1. Information We Collect and Store

1.1 Information You Provide

The App stores the following information locally on your device when you create accounts, add members, record transactions, or manage customers:

Category Data Location
Association Account SLPA name, full name, mobile number, 4-digit PIN, security question and answer, profile image Local SQLite database + filesystem
Member Profile Full name, mobile number, 4-digit PIN, security question and answer Local SQLite database
Customer Records Full name, phone number, municipality, barangay, landmark, credit limit Local SQLite database

1.2 Information Retrieved via Google APIs

When you configure the Google Drive backup feature, the App accesses the following information from your Google Account:

  • Google Account ID (immutable identifier) — used to identify the configured shared account
  • Google Account email address — displayed in the App for reference
  • OAuth 2.0 access tokens and refresh tokens — used to authenticate Google Drive API requests. These tokens are stored in the device’s secure hardware-backed storage (Android Keystore), not in the App’s database.

1.3 Information We Do NOT Collect

The App does not collect:

  • Device identifiers (IMEI, serial numbers, advertising ID)
  • GPS or precise location data
  • Contacts, call logs, or SMS data
  • Biometric data (fingerprint templates stay on device)
  • Browsing history or usage analytics
  • Crash reports or diagnostic logs
  • Any information from children under 13

2. How We Use Information

All information collected is used exclusively for the following purposes:

  • App Authentication: PIN verification and session management
  • Store Operations: Recording sales, inventory, expenses, customer credit, and generating financial reports
  • Google Drive Backup & Restore: Creating encrypted-token-authenticated backup archives in Google Drive and restoring them when requested
  • Product Alerts: Sending email notifications via EmailJS when products are edited or deleted (fire-and-forget; no personally identifiable information beyond product details is sent)

3. Google API Services — Limited Use Disclosure

The App uses Google API services (Google Sign-In and Google Drive API) solely for the backup and restore feature. The App’s use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

3.1 OAuth Scope

The App requests the following OAuth scope:

https://www.googleapis.com/auth/drive.file

This scope grants the App access only to files and folders that it creates in Google Drive. The App cannot access any other files in your Google Drive.

3.2 Data Accessed via Google APIs

Data How It Is Used Storage
Google Account ID Verify that the authenticating user matches the configured shared account Stored locally in backup_settings table
Google Account email Display in backup settings for user reference Stored locally in backup_settings table
OAuth tokens Authenticate Drive API requests (create, list, download, delete backup files) Android Keystore (secure hardware-backed storage) — NOT in App database
Backup files (ZIP archives) Uploaded to or downloaded from the App’s Drive folder for backup/restore Google Drive (user’s own storage, only within App-created folders)

3.3 Limited Use Compliance

The App’s use of Google user data meets Limited Use requirements because:

  • Data obtained through Google APIs is used only to provide the backup and restore feature
  • No data is transferred to third parties — no advertising networks, analytics providers, or data brokers
  • No data is used for advertising, remarketing, or machine learning
  • No data is used for building user profiles or improving unrelated products
  • The App uses the most restrictive scope (drive.file) that allows the feature to function
  • Users can revoke access at any time via their Google Account settings or by disconnecting within the App

4. Data Storage and Security

4.1 Local Storage

  • SQLite Database: The App stores all operational data in a local SQLite database file (app_data.db) on the device. This database is not encrypted at rest.
  • SharedPreferences: Session and preference data are stored using Android SharedPreferences. This data is not encrypted at rest.
  • Filesystem: User-uploaded images (profile, product, receipts) are stored in the app’s documents directory.
  • Android Keystore: Google OAuth tokens are stored in hardware-backed secure storage.

4.2 Google Drive Storage

  • Backup archives are uploaded to a dedicated folder structure under the App’s Google Drive folder: EMPOWER/[Organization Name]/backup_*.zip
  • Backup archives are ZIP files that are not encrypted. Access to their content is controlled solely by Google Drive permissions.
  • Each backup contains: the full SQLite database, user-uploaded images, and a metadata JSON file.
  • The App retains the latest 10 backups per organization; older backups are automatically deleted.

4.3 PIN Storage Disclosure

4-digit PINs are stored as plain text in the local SQLite database. This is a known limitation of the current implementation. PINs are never transmitted over a network or uploaded to any server (except as part of a full database backup archive uploaded to Google Drive).

5. Data Retention and Deletion

5.1 Local Data

  • Local data persists on the device until you delete it using the App’s “Clear All Data” function or uninstall the App.
  • The “Clear All Data” function removes all operational data (products, inventory, sales, expenses, customers, transactions) while preserving the App’s schema for a fresh start.
  • Uninstalling the App removes the local SQLite database, SharedPreferences, and app-specific files.

5.2 Google Drive Backups

  • Backup archives remain in your Google Drive until you delete them or the App’s automatic retention (latest 10) removes older ones.
  • Disconnecting the App from Google Drive stops future backups but does not delete existing backup archives from Drive.

5.3 How to Delete Your Data

  1. Delete all local App data: Open the App, navigate to Settings → Clear All Data. This removes all local operational data.
  2. Delete Google Drive backups: Open the App’s Backup Settings → disconnect Google Drive, then visit drive.google.com and delete the “EMPOWER” folder to remove all backup archives. Alternatively, you can delete individual backup files from within the App’s restore screen.
  3. Revoke Google Account access: Visit your Google Account permissions page and revoke access for the E.M.P.O.W.E.R application. This immediately prevents the App from accessing your Google Drive.
  4. Uninstall the App: Removing the App from your device deletes all locally stored data.
